# Create a deal

Create a deal with this in-depth tutorial using IQM's Inventory API.

## About IQM deals

The Inventory API allows you to create and manage advertising deals. IQM offers two kinds of private deals:

  * **Private Marketplace (PMP)** deals are a type of programmatic advertising arrangement that allows Advertisers to purchase ad inventory through a private, invitation-only auction.
  * **Programmatic Guaranteed (PG)** deals are a direct negotiation between one publisher and one Advertiser that offer budget predictability and avoid auction volatility by ensuring a fixed amount of ad inventory at a pre-negotiated price.

### More resources
  * [Inventory API](/guidelines/inventory-api) guidelines
  * [Optimize your inventory](/tutorials/optimize-your-inventory/) tutorial
  * [Ad inventory and placements<ExternalLink />](https://help.iqm.com/en/collections/2908807-ad-inventory-and-placements) Help Center article

## Before you begin

To create a deal, the following are required:

  * An account on the IQM platform
    * See [Getting started](/getting-started/before-you-begin) section to create an account and request a Client ID and Client Secret
  * A campaign, only for assigning a deal to an existing campaign
    * For a PMP deal, see the [Create a campaign](/quickstart-guides/create-a-campaign-quickstart) quickstart guide
    * A PG campaign can't be created without an active PG deal, so create the PG deal first and then use it in [Create a PG campaign](/tutorials/create-a-pg-campaign). You can assign more PG deals to the campaign afterwards.

## Assign deals to a campaign

<CopyUrl method="PATCH" url="https://api.iqm.com/api/v3/cmp/pg/campaigns/mappings" />
<br /><CopyUrl method="PATCH" url="https://api.iqm.com/api/v3/cmp/pmp/campaigns/mappings" />

<div class="endpoint-container">
  <div class="child1">

Deals can be assigned or removed to/from campaigns. PG deals may only be assigned to PG campaigns; and PMP deals may only be assigned to Advanced campaigns.

Both endpoints require an Advertiser organization. A request can't list the same campaign and deal pair in both an <var>assign</var> and a <var>deassign</var> operation.

| Request schema | |
| --- | --- |
| `operations` <br /><span class="type-text">array</span> | Operations specifying the action, campaign IDs and PMP deal IDs. |
| `action` <br /><span class="type-text">string</span> | Action to perform: <var>assign</var> or <var>deassign</var>. |
| `campaignIds` <br /><span class="type-text">array of integers</span> | Campaign IDs to assign deals or remove deals from. |
| `pmpDealIds` <br /><span class="type-text">array of integers</span> | PMP deal IDs to assign/remove to/from campaigns. |
| `pgDealIds` <br /><span class="type-text">array of integers</span> | PG deal IDs to assign/remove to/from campaigns. |
