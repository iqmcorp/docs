# Create a Contextual audience

Create your first audience using IQM's API in this step-by-step quickstart guide.

The following endpoints are used to create a Contextual audience:

<CopyUrl method="POST" url="https://api.iqm.com/api/v3/ua/oauth/token" />
<br /><CopyUrl method="POST" url="https://api.iqm.com/api/v3/audience/contextual" />
<br /><CopyUrl method="GET" url="https://api.iqm.com/api/v3/audience/contextual/{audienceId}" />

## About IQM Contextual audiences

IQM's Contextual audience allows you to make groupings of users based on their online activity. By specifying keywords and/or URLs, IQM builds a Contextual audience as users visit sites relevant to those parameters within a target timeframe.

Contextual audiences have two kinds of data collection periods:
  * **static** - a timeframe between two dates, from up to 180 days in the past to up to 90 days in the future, with a maximum 60-day period
  * **dynamic** - a rolling timeframe of up to the last 60 days from today with data refreshing every 24 hours

## Create a Contextual audience using the IQM API

This quickstart guide covers how to create a Contextual audience using both keywords and URLs and each type of data collection period.

The minimum requirements to perform this task are: logging in with authentication credentials, creating a Contextual audience, and checking the audience status. Once these steps are accomplished, more can be learned about IQM's API through the [guidelines](/guidelines/) pages. 

1. Log in
   * Optional if you have already logged in and have a token
1. Create a Contextual audience
1. Check the audience status

### Step 2: Create a Contextual audience

<CopyUrl method="POST" url="https://api.iqm.com/api/v3/audience/contextual" />

<p />You can determine how a Contextual audience forms groupings by indicating a list of relevant keywords and/or URLs. IQM adds users to the Contextual audience when they visit a site relevant to those keywords or URLs. 

The request schema table below details the supported fields for creating a Contextual audience. Steps 2a and 2b detail two different ways to perform this action, however keywords and URLs can also be used together to create a Contextual audience.

<div style={{ maxWidth: "750px"}}>
| Request schema | |
| --- | --- |
| `audienceName` <br /><span class="type-text">string</span> <span class="required-text">required</span> | Audience name, up to 255 characters. |
| `keywords` <br /><span class="type-text">array of strings</span> | Keywords to generate a Contextual audience. Send an empty array (<var>[]</var>) if you only use URLs. |
| `urls` <br /><span class="type-text">array of strings</span> | The publisher sites visited by a user. Each URL must include a scheme (<var>https://</var>). Send an empty array (<var>[]</var>) if you only use keywords. |
| `frequency` <br /><span class="type-text">integer</span> <span class="required-text">required</span> | The number of times a user visits the publisher(s) relevant to one or more keywords or URLs added to the Contextual audience, from <var>1</var> to <var>10</var>. |
| `timezoneId` <br /><span class="type-text">integer</span> <span class="required-text">required</span> | [Timezone ID](/guidelines/master-api#get-timezones) that sets the data collection start time. |
| `dataCollectionMethodId` <br /><span class="type-text">integer</span> <span class="required-text">required</span> | **static** (<var>1</var>): data collection over a fixed set of dates. <br />**dynamic** (<var>2</var>): data collection over a rolling timeframe, with data refreshes every 24 hours. |
| `startDate` <br /><span class="type-text">integer</span> | Unix epoch start date, in milliseconds. Required if the data collection method is **static**. |
| `endDate` <br /><span class="type-text">integer</span> | Unix epoch end date, in milliseconds. Required if the data collection method is **static**. |
| `dataCollectionDays` <br /><span class="type-text">integer</span> | Number of days in the rolling data collection timeframe, up to <var>60</var>. Required if the data collection method is **dynamic**. |
| `audienceSubtypes` <br /><span class="type-text">array of integers</span> | Healthcare workspaces only. Audience subtype IDs: <var>3</var> (HCP), <var>4</var> (Nurse), <var>5</var> (Non-NPI Nurse). One audience is created per subtype. |
</div>

#### Step 2a: Contextual audience with keywords

<div class="endpoint-container">
  <div class="child1">

You can create a Contextual audience with keywords and just a few other parameters. You need to pass an <var>audienceName</var> and select one or more <var>keywords</var>. In the provided request sample (seen in the code block in the right-side column) the chosen keywords are "politics", "voters", and "california". 

Next you need to decide a <var>frequency</var> from 1-10. This determines how many times a user must visit a site relevant to the chosen keywords to be added to the Contextual audience.

A Contextual audience also requires specifying a timeframe for data collection. In this example you can choose a **static** data collection method by passing <var>1</var> as the <var>dataCollectionMethodId</var>. This method requires [Unix Epoch](https://www.epochconverter.com/) values for the <var>startDate</var> and <var>endDate</var> fields.

:::info 

The start date of a Contextual audience must be within the last 180 days. 

Contextual audiences support a static or dynamic data collection period of up to 60 days.

:::

Lastly, a timezone ID is required to determine the data collection timeframe. An ID of <var>29</var> designates the US/Eastern time zone. 

</div>
<div class="child2">

<Tabs>
<TabItem value="JSON" label="JSON" default>

```json title="Request sample"
{
  "audienceName": "California Politics",
  "frequency": 5,
  "keywords": ["politics", "voters", "california"],
  "urls": [],
  "dataCollectionMethodId": 1,
  "startDate": 1797310800000,
  "endDate": 1800507599000,
  "timezoneId": 29
}
```

```json title="Response 200"
{
  "success": true,
  "data": {
    "message": "California Politics audience created successfully",
    "audienceIds": [
      1183879
    ]
  }
}
```

#### Step 2b: Contextual audience with URLs

<div class="endpoint-container">
  <div class="child1">

You can also create a Contextual audience with URLs. You need to pass the desired websites as an array of strings in the <var>urls</var> field.

As in Step 2a, you need to pass integers for <var>frequency</var> and <var>timezoneId</var>.

In this example you can choose a **dynamic** data collection method by passing <var>2</var> as the <var>dataCollectionMethodId</var>. This method requires passing a period of days (1-60) in the <var>dataCollectionDays</var> field. 

</div>
