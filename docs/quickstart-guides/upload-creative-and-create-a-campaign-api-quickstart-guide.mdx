# Create a PG campaign

Create a Programmatic Guaranteed (PG) campaign with this in-depth tutorial using IQM's API.

The following endpoints are used to create a PG campaign:

<CopyUrl method="POST" url="https://api.iqm.com/api/v3/ua/oauth/token" />
<br /><CopyUrl method="POST" url="https://api.iqm.com/api/v3/cmp/pg/campaigns/add" />
<br /><CopyUrl method="GET" url="https://api.iqm.com/api/v2/cmp/campaign/{campaignId}" />


## About IQM PG campaigns

IQM's PG campaigns define the individual marketing strategies of your ads with an inventory purchased directly from a specific publisher. By specifying the supported parameters you can use the API to create a new PG campaign.

### More resources
  * [Campaigns overview<ExternalLink />](https://help.iqm.com/en/articles/11497668-campaigns-overview) Help Center article
  * [Campaign API](/guidelines/campaign-api) guidelines

## Before you begin

To create a PG campaign, the following are required:

1. An account on the IQM platform
   *  See [Getting started](/getting-started/before-you-begin) section to create an account and request a Client ID and Client Secret
1. An approved and running creative 
   * See [Upload a creative](/quickstart-guides/upload-a-creative-quickstart) quickstart guide
1. An insertion order
   * See [Create a campaign](/quickstart-guides/create-a-campaign-quickstart) quickstart guide to create a new insertion order
1. A conversion
   * See [Create a conversion](/tutorials/create-a-conversion) tutorial
1. A PG deal
   * See [Create a deal](/tutorials/deal-guide) tutorial


## Create a PG campaign using the IQM API

This tutorial covers how to create a campaign and upload a creative. 

The minimum requirements to perform this task are: logging in with authentication credentials, uploading a creative, and creating a campaign. Once these steps are accomplished, more can be learned about IQM's API through the [guidelines](/guidelines/) pages.

1. Log in
    * Optional if you have already logged in and have a token
1. Create a PG campaign
    * 2.1 Create a PG campaign, provide necessary targeting parameters
    * 2.2 Check campaign's status

      }
    }
