# Upload a Matched audience

Upload a Matched audience with this in-depth tutorial using IQM's API.

Get started uploading a Matched audience with the following endpoints:

<CopyUrl method="POST" url="https://api.iqm.com/api/v3/ua/oauth/token" />
<br /><CopyUrl method="POST" url="https://api.iqm.com/api/v3/audience/static/column-list" />
<br /><CopyUrl method="POST" url="https://api.iqm.com/api/v3/audience/matched" />
<br /><CopyUrl method="GET" url="https://api.iqm.com/api/v3/audience/matched/{audienceId}" />

## About IQM Matched audience

The Audience API allows you to upload an audience for matching in XLSX or CSV format. Once uploaded and processed, the Matched audience can be used for advertising campaign targeting.

### More resources
  * [Matched audience<ExternalLink />](https://help.iqm.com/en/collections/13049392-matched-audience) Help Center article
  * [Audience API](/guidelines/audience-api) guidelines

## Before you begin

To upload a Matched audience, the following are required:

1. An account on the IQM platform
   *  See [Getting started](/getting-started/before-you-begin) section to create an account and request a Client ID and Client Secret
1. CSV or XLSX file for matching

<div style={{ maxWidth: "1000px" }}>
:::info 

**File requirements for audience matching:**
  * CSV or XLSX file for audience matching with maximum 1GB or 5M records
  * Without Voter ID / Email / Phone / Address in the file
    * One of the following system field combinations is required for matching
      * First Name, Last Name, Zip, State
      * Last Name, Street Address, Zip, State
      * Street Address, Zip, State
    * Other fields are optional and can be added along with the above fields
  * With Voter ID / Email / Phone / Address in the file
    * Only one of these fields is required - Voter ID or Email or Phone, or Address. The preferred format for full address is Street, City, Zip, and State
    * Other fields are optional and can be added along with one of the above fields

:::
</div>

## Upload a Matched audience using the IQM API

This tutorial covers how to create a Matched audience.  

The minimum requirements to perform this task are: logging in with authentication credentials, selecting columns for matching, and uploading an audience. Once these steps are accomplished, more can be learned about IQM's API through the [guidelines](/guidelines/) pages.

1. Log in
   * Optional if you have already logged in and have a token
1. Get audience request properties
   * Optional if you already know desired/supported columns
1. Upload a Matched audience
   * Upload the audience with parameters from the previous steps
1. Check audience status
   * A Matched audience requires processing and approval before it can be used for targeting

### Step 1: Log in

<CopyUrl method="POST" url="https://api.iqm.com/api/v3/ua/oauth/token" />

<div class="endpoint-container">
  <div class="child1">

To log in, send the <var>Authorization: Basic</var> header with your Base64-encoded Client ID and Client Secret, and send the request body as form data (<var>application/x-www-form-urlencoded</var>). The Login API returns an OAuth-compliant response with an Organization Workspace ID (<var>owId</var>), a unique identifier for each Organization. This ID is used for any further API communications.

For further information see [OAuth token](/guidelines/user-api#oauth-token).

<div class="endpoint-container">
  <div class="child1">

To upload a Matched audience, you need to gather some information about your audience and file to fill in the required parameters for the upload endpoint. These include:

| Parameter | Description |
| --- | --- |
| Audience subtype ID <br /><span class="type-text">Healthcare vertical</span> | The [Audience subtype ID](/guidelines/audience-api/#audience-subtype-list) for the Matched audience being uploaded. <br /><EnumWidget values={audienceSubtypes} /> |
| Column IDs for matching | A list of [Column IDs](/guidelines/audience-api/#matched-column-list) for matching which correspond to the columns in the file being uploaded. |
| Data format ID | The [Data format ID](/guidelines/audience-api/#data-formats-list-for-matched-audience) corresponds to the type of identifiers being uploaded. <br /><EnumWidget values={dataFormats} /> |
| Data partner ID | The [Data partner ID](/guidelines/audience-api/#data-partners-list-for-matched-audience) corresponds to the source of the data being uploaded and is used for reporting purposes. <br /><EnumWidget values={dataPartners} /> |
| Column combination ID <br /><span class="type-text">Political vertical</span> | The [Column combination ID](/guidelines/audience-api/#matched-column-combinations) corresponds to the combination of columns being used for matching. |

The <var>column-list</var>, <var>data-partners</var>, and <var>column-combinations</var> endpoints require the <var>audienceTypeId</var> query parameter (<var>1</var> for Matched audiences), and accept an optional <var>audienceSubtypeId</var> for Healthcare subtypes. For example, <var>GET /api/v3/audience/static/column-list?audienceTypeId=1</var> returns the columns shown in the response sample. Each column's <var>dataFormatIds</var> lists the data formats it accepts; columns without <var>dataFormatIds</var> don't take a <var>dataFormatId</var>.
