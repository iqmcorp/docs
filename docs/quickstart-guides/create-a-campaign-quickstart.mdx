# Create a campaign

Create your first campaign using IQM's API in this step-by-step quickstart guide.

The following endpoints are used to create an insertion order (IO) and start a campaign:

<CopyUrl method="POST" url="https://api.iqm.com/api/v3/ua/oauth/token" />
<br /><CopyUrl method="POST" url="https://api.iqm.com/api/v3/cmp/io/add" />
<br /><CopyUrl method="POST" url="https://api.iqm.com/api/v2/cmp/campaigns/add" />
<br /><CopyUrl method="GET" url="https://api.iqm.com/api/v2/cmp/campaign/{campaignId}" />

## About IQM campaigns

IQM's campaigns define the individual marketing strategies of your ads. By specifying the supported parameters you can use the API to create a new campaign. 

### More resources
  * [Campaigns overview<ExternalLink />](https://help.iqm.com/en/articles/11497668-campaigns-overview) Help Center article
  * [Campaign API](/guidelines/campaign-api) guidelines

## Before you begin

To create a campaign, the following are required:

1. An account on the IQM platform
   *  See [Getting started](/getting-started/before-you-begin) section to create an account and request a Client ID and Client Secret
1. An approved and running creative 
   * See [Upload a creative](/quickstart-guides/upload-a-creative-quickstart) quickstart guide to upload a creative

## Create a campaign using the IQM API

This quickstart guide covers how to create an insertion order and a new campaign. 

The minimum requirements to perform this task are: logging in with authentication credentials, creating an IO, and starting a new campaign. Once these steps are accomplished, more can be learned about IQM's API through the [guidelines](/guidelines/) pages.

1. Log in
    * Optional if you have already logged in and have a token
1. Create an insertion order 
    * Optional if already created
1. Create a campaign
1. Check campaign status

### Step 1: Log in

<CopyUrl method="POST" url="https://api.iqm.com/api/v3/ua/oauth/token" />

<div class="endpoint-container">
  <div class="child1">

To log in, send the <var>Authorization: Basic</var> header with your Base64-encoded Client ID and Client Secret, and send the request body as form data (<var>application/x-www-form-urlencoded</var>). The Login API returns an OAuth-compliant response with an Organization Workspace ID (<var>owId</var>), a unique identifier for each Organization. This ID is used for any further API communications.

For further information see [OAuth token](/guidelines/user-api#oauth-token).

<OAuthHeaders />


| Request schema  |  |
| ----  | --- |
| `grant_type` <br /><span class="type-text">string</span> <span class="required-text">required</span> | <var>password</var> for login <br />[OAuth Grant Types<ExternalLink />](https://oauth.net/2/grant-types/) |
| `username` <br /><span class="type-text">string</span> <span class="required-text">required</span> | User account email |
| `password` <br /><span class="type-text">string</span> <span class="required-text">required</span> | User account password |

### Step 2: Create an insertion order

<CopyUrl method="POST" url="https://api.iqm.com/api/v3/cmp/io/add" />

<div class="endpoint-container">
<div class="child1">

Before a campaign can be started an insertion order must be created. An insertion order is a contractual agreement that outlines the terms and conditions for one or more advertising campaigns. Once created, a campaign can be created and assigned to an IO. 

The minimum required values for IO creation are as listed below. See a complete table of [Resource Properties](/guidelines/campaign-api#insertion-order-resource-properties) for all supported values. 

Read more: [Insertion orders (IO) overview<ExternalLink />](https://help.iqm.com/en/articles/8365220-what-is-an-insertion-order)

| Request schema | |
| --- | --- |
| `ioName` <br /><span class="type-text">string</span> | IO name |
| `ioStartTime` <br /><span class="type-text">integer</span> | Unix epoch timestamp (in milliseconds) of IO start time |
| `ioEndTime`  <br /><span class="type-text">integer</span> | Unix epoch timestamp (in milliseconds) of IO end time |
| `ioTotalBudget` <br /><span class="type-text">integer</span> | IO budget |
| `ioStatusID` <br /><span class="type-text">integer</span> | [Status ID](/guidelines/campaign-api#get-io-status-list) <br /><EnumWidget values={ioStatus} /> |
| `ioTimeZoneId` <br /><span class="type-text">integer</span> | [Timezone ID](/guidelines/master-api#get-timezones) for IO |
| `isAutoSumIoTotalBudget` <br /><span class="type-text">boolean</span> | If <var>true</var> Keeps IO budget same as total budget of all included campaigns |
| `ioBudgetTypeId` <br /><span class="type-text">integer</span> | [IO budget type ID](/guidelines/campaign-api#get-list-of-campaign-budget-types) <br /><EnumWidget values={budgetTypes} />
| `ioBudgetDistributionMethodId` <br /><span class="type-text">integer</span> | [Budget distribution method ID](/guidelines/campaign-api#get-list-of-budget-distribution-methods) <br /><EnumWidget values={budgetDistributionMethods} /> |

### Step 3: Create a campaign 

<CopyUrl method="POST" url="https://api.iqm.com/api/v2/cmp/campaigns/add" />

<div class="endpoint-container">
  <div class="child1">

Create a new campaign in <var>pending</var> status.

Select <var>campaignType</var>: <var>1</var> for an "Advanced" campaign. 

Use the <var>ioId</var> in the response from the IO you created in Step 2.

The minimum required values for creating a campaign are as listed below. See the [Create new campaign](/guidelines/campaign-api#create-new-campaign) documentation for the complete request schema. 

:::info

Make sure that the <var>budgetTypeId</var> of your campaign matches the <var>ioBudgetTypeId</var> of your IO. 

:::
