# Create a conversion

Create a conversion with this in-depth tutorial using IQM's API.

The following endpoints are used to create a conversion and assign it to a campaign:

<CopyUrl method="POST" url="https://api.iqm.com/api/v3/ua/login" />
<br /><CopyUrl method="POST" url="https://api.iqm.com/api/v3/conversion/pixel/add" />
<br /><CopyUrl method="POST" url="https://api.iqm.com/api/v3/conversion/assign-to/campaign" />

## About IQM conversions

IQM uses conversions as a tool to track user traffic for your campaigns. 

The IQM platform supports three types of conversions:
  * **Pixel** conversions are client-side tracking and they feature advanced settings for fine-tuned optimization.
  * **Postback** conversions use server-to-server tracking, sending conversion data directly from your server to IQM without relying on browser-based JavaScript or cookies.
  * **Universal Pixel** conversions are client-side and use a single JavaScript snippet that can track multiple conversion events across your site without deploying separate per-page pixels.

### More resources
  * [Conversions and tracking<ExternalLink />](https://help.iqm.com/en/collections/3219750-choose-your-conversion) Help Center article
  * [Conversions API](/guidelines/conversion-api) guidelines

## Before you begin

To create a conversion, the following are required:

1. An account on the IQM platform
   *  See [Getting started](/getting-started/before-you-begin) section to create an account and request a Client ID and Client Secret
1. A draft campaign
   *  See [Create a campaign](/quickstart-guides/create-a-campaign-quickstart)

## Create a conversion using the IQM API

This tutorial covers how to create a conversion and assign it to a campaign.

The minimum requirements to perform this task are: logging in with authentication credentials, creating a conversion, and assigning it to a campaign. Once these steps are accomplished, more can be learned about IQM's API through the [guidelines](/guidelines/) pages.

1. Log in
    *  Optional if you have already logged in and have a token
1. Create a conversion
1. Assign conversion to a campaign

### Step 3: Assign a conversion to a campaign

<CopyUrl method="POST" url="https://api.iqm.com/api/v3/conversion/assign-to/campaign" />

<div class="endpoint-container">

Assign a conversion to a campaign while validating conversion IDs and campaign IDs. 

Pass the conversion <var>id</var> created in Step 2 in the <var>conversionIdList</var> array along with the campaign ID in the <var>addCampaignsList</var> array to assign the created conversion to the desired campaign. 

:::info 

Conversions can be assigned, updated, or removed from a campaign only before the campaign is running.

:::
