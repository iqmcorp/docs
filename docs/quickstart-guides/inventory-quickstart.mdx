# Optimize your inventory

Optimize your inventory with this in-depth tutorial using IQM's Inventory API.

The following endpoints are used to search inventory, assign campaign targeting, and create an inventory group:

<CopyUrl method="POST" url="https://api.iqm.com/api/v3/ua/oauth/token" />
<br /><CopyUrl method="GET" url="https://api.iqm.com/api/v3/inv/inventories/list" />
<br /><CopyUrl method="POST" url="https://api.iqm.com/api/v3/inv/groups" />
<br /><CopyUrl method="POST" url="https://api.iqm.com/api/v3/inv/group/addMappings" />
<br /><CopyUrl method="POST" url="https://api.iqm.com/api/v3/cmp/inventorygroup/includeExclude" />
<br /><CopyUrl method="GET" url="https://api.iqm.com/api/v3/inv/group/{groupId}/shared/campaign/list" />

## About IQM inventory

IQM's advanced algorithm determines the most relevant ads to display to a user based on their activity and the content of a given page. Inventories provide you a way to organize collections or groups based on criteria such as ad format, placement type, targeting options, and other properties.

### More resources
  * [Ad inventory and placements<ExternalLink />](https://help.iqm.com/en/collections/2908807-ad-inventory-and-placements) Help Center article
  * [Inventory API](/guidelines/inventory-api) guidelines

## Before you begin

To search and manage inventory, the following are required:

1. An account on the IQM platform
   *  See [Getting started](/getting-started/before-you-begin) section to create an account and request a Client ID and Client Secret
1. A campaign
   *  See [Create a campaign](/quickstart-guides/create-a-campaign-quickstart)

## Optimize your inventory using the IQM API 

This tutorial covers how to create and manage inventory groups and target inventory with campaigns.

The minimum requirements to perform this task are: logging in with authentication credentials, selecting inventory, assigning it to a campaign, and creating an inventory group. Once these steps are accomplished, more can be learned about IQM's API through the [guidelines](/guidelines/) pages.

1. Log in
    *  Optional if you have already logged in and have a token
1. Search inventory 
    * Optional if you already have pre-selected inventory to use
1. Create an inventory group 
    * Optional if you already have an existing inventory group to use, skip to next step
1. Update an inventory group
1. Target campaigns with an inventory group
1. Get inventory group campaign details

### Step 1: Log in

<br /><CopyUrl method="POST" url="https://api.iqm.com/api/v3/ua/oauth/token" />

<div class="endpoint-container">
  <div class="child1">

To log in, send the <var>Authorization: Basic</var> header with your Base64-encoded Client ID and Client Secret, and send the request body as form data (<var>application/x-www-form-urlencoded</var>). The response contains an OAuth access token.

To find the Organization Workspace IDs that you have access to, use [Get list of accessible Organizations](/guidelines/workspace-api#get-list-of-accessible-organizations).

### Step 3: Create an inventory group

### Step 5: Target campaigns with an inventory group

<CopyUrl method="POST" url="https://api.iqm.com/api/v3/cmp/inventorygroup/includeExclude" />

<div class="endpoint-container">
  <div class="child1">

Once an inventory group has been created, you can attach it to a campaign for targeting. Pass the inventory group ID in the <var>groupIds</var> array and the desired campaign ID in the <var>includedCampaignIds</var> field.

Each request replaces the group's list of included campaigns. To keep campaigns that already target the group, send their IDs again with the new ones.

| Request schema | |
| --- | --- |
| `groupIds` <br /><span class="type-text">array of integers</span> <span class="required-text">required</span> | Inventory group IDs. |
| `includedCampaignIds` <br /><span class="type-text">string</span> <span class="required-text">required</span> | Comma-separated campaign IDs to include targeting. This replaces the group's current list. Send an empty string if there are none. |
| `excludedCampaignIds` <br /><span class="type-text">string</span> <span class="required-text">required</span> | Comma-separated campaign IDs to exclude targeting. Send an empty string if there are none. |

</div>
