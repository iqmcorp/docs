## About IQM Bid Model

The Bid Model API allows you to optimize advertising campaigns for better performance. You can fine-tune metrics such as where ads appear (Include/Exclude), manage campaign priority, and dimensions by which a campaign is subdivided.

The Bid Model comprises the following tools:

  * **Spend Ratio**: determines how the campaign budget is distributed across various dimensions, expressed as a percentage in two types.
    1.  Strict: budget is allocated up to its specified percentage as able, but underspends if unable to meet that ratio.
    1.  Flexible: budget reallocates if unable to fulfill its specified percentage.
  * **Dimension priority**: dictates the sequence of bidding for specified targeting dimensions, expressed as a range of 1-10.
  * **Bid Modifier**: adjusts the base bid of a campaign for the specified dimension that is modified, expressed as a multiplier in a range of 0.1-100.

## Before you begin

To create a Bid Model the following are required:

1. An account on the IQM platform
   *  See [Before you begin](/getting-started/before-you-begin) to create an account and request a Client ID and Client Secret
   * See [Sign up and authenticate](/quickstart-guides/authentication-quickstart-guide) to learn how to log in and receive an authentication token
1. A campaign that meets the following criteria:
   *  Duration of at least 3 days
   *  Daily budget of at least $100
   *  Base bid and max bid price must be defined

## Create a Bid Model using the IQM API

This tutorial covers how to create a Bid Model.

The minimum requirements to perform this task are: logging in with authentication credentials, checking a campaign's eligibility, and creating a Bid Model. Once these steps are accomplished, more can be learned about IQM's API through the [guidelines](/guidelines/) pages.

1. Check campaign for eligibility
    * 1.1: Check insertion order (IO) for campaign eligibility
1. Select a dimension
1. Create a Bid Model

### Step 3: Create a Bid Model 

<CopyUrl method="PUT" url="https://api.iqm.com/api/v3/bm/campaigns/{campaignId}/bid-models/{dimensionId}" />

<div class="endpoint-container">
<div class="child1">

Once you have determined your campaign is eligible, you can pass the <var>campaignId</var> and your selected <var>dimensionId</var> to create a Bid Model. Review the Bid Model tools descriptions in the [About](#about-iqm-bid-model) section, the [Bid Model criteria](#bid-model-criteria), and the Request schema table below to create a Bid Model.

See the [Manage Bid Model settings](/guidelines/bid-model-api/#manage-bid-model-settings) endpoint for full documentation. 

:::info

Spend Ratio:
  * Strict Spend Ratios must equal 100% across all allocated dimensions.
  * Flexible Spend Ratios require a dimension priority.
:::


:::tip

Group multiple dimension entities into a bundle to apply the same Bid Modifier and Spend Ratio to all entities in the bundle. 

See the [Create Bid Model bundle](/guidelines/bid-model-api/#create-bid-model-bundle) endpoint for more information on how to create a bundle, then use the `bundleName` and `entityIds` in your requests.

:::

| `dimensionId` <br /><span class="type-text">integer</span> | Dimension ID |
