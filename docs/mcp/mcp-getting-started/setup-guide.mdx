# Setup Guide

## Overview 

IQM MCP is a powerful interface that allows AI models to access information and functionality of IQM's various apps. Use this setup guide to get up and running with IQM MCP. 

## Before You Begin

Before you can use the IQM MCP, you will need an account on the [IQM Platform](https://app.iqm.com/). If you do not have an account, reach out to IQM Support (support@iqm.com) or your IQM representative to get started.

You will also need either [Claude Desktop](https://www.claude.com/download) or [GitHub Copilot](https://github.com/features/copilot) installed on your computer.

### Authorization Credentials 

You will need the following credentials to set up your IQM MCP connection:
* Organization Workspace ID
* Bearer Token


1. Using your IQM credentials, log in to the [MCP portal](https://mcp.iqm.com/).
1. In the left panel you will find an "Authorization Token" and a "Default Customer ID" (OWID) to use in your MCP session.

## MCP Setup

### Tool Installation

Run the following commands to install the required tools for MCP:

<Tabs>
<TabItem value="macos" label={<><MacOS /> macOS</>}>

##### Step 1: Install uv 

```bash
brew install uv
```

##### Step 2: Install the Windsor MCP Proxy

```bash
uv tool install mcp-proxy
```

##### Step 3: Locate the Installed Path

```bash
which mcp-proxy
```

This will return the path to the installed mcp-proxy tool. You will need this path for Step 3 below.

```
/Users/<USERNAME>/.local/bin/mcp-proxy
```

</TabItem>
<TabItem value="windows" label={<><Windows /> Windows</>}>

##### Step 1: Install uv

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

##### Step 2: Install the Windsor MCP Proxy

```powershell
uv tool install mcp-proxy
```

##### Step 3: Locate the Installed Path

```powershell
where.exe mcp-proxy
```

This will return the path to the installed mcp-proxy tool. You will need this path for Step 3 below.

```
C:\Users\<USERNAME>\.local\bin\mcp-proxy.exe
```

</TabItem>
</Tabs>

### Claude Desktop Configuration

##### Step 1: Retrieve Config

In the [MCP Portal](https://mcp.iqm.com/), copy the JSON from the MCP Client Configuration window. 

<center><img className='diagram' src={MCPConfig} /></center>

##### Step 2: Open Claude Desktop

In Claude Desktop navigate to **Claude Desktop > Settings > Developer > Edit Config** and paste the JSON configuration from the MCP Portal.

##### Step 3: Insert Credentials

In the JSON configuration, replace the placeholder values for <var>WORKSPACE_ID</var>, <var>BEARER_TOKEN</var>, and <var>USERNAME</var> with the values from the MCP Portal ([Authorization Credentials](#authorization-credentials)) and step 3 from [Tool Installation](#tool-installation).

##### Step 4: Save Configuration

After inserting your credentials, save the configuration file and restart Claude Desktop. You are now ready to use IQM MCP!

### Copilot Configuration

In VS Code navigate to **VS Code > Preferences > Settings > Chat > MCP > Discovery**. You can enable this feature to discover your Claude MCP Configuration and connect to IQM MCP with Copilot.

## MCP Tool Selection

### Claude Desktop

In Claude Desktop you can see the available tools in two different ways:

##### 1. Settings

Navigate to **Claude Desktop > Settings > Connectors**. You will see a list of available servers, their corresponding tools, and their permissions.

##### 2. Tool List

You can also toggle on/off tools by server in the chat window. Click the "+" icon and view **Connectors** to see the available servers.

<center><img className='diagram' src={MCPClaudeTools} /></center>

### GitHub Copilot

In GitHub Copilot you can see the available tools in the chat window or view their settings:

##### 1. Settings

At the top of the window click the **Open Quick Access** bar and then **Show and Run Commands > MCP: List Servers** (you may need to type "MCP" to filter the commands). This will display the available servers and their settings.

##### 2. Tool List

You can also toggle on/off tools by server from the chat window. Click the **Configure Tools** button and a server/tool list will appear. You may need to click the **Update Tools** button to refresh the list of available tools.

:::warning
GitHub Copilot enforces a limit of 128 tools per request. If you have more than 128 tools enabled, you may need to disable some tools to avoid errors.
:::
