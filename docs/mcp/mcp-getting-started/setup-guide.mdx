# Setup Guide

## Overview 

IQM MCP is a powerful interface that allows AI models to access information and functionality of IQM's various apps. Use this setup guide to get up and running with IQM MCP. 

## Before You Begin

Before you can use the IQM MCP, you will need an account on the [IQM Platform](https://app.iqm.com/). If you do not have an account, reach out to IQM Support (support@iqm.com) or your IQM representative to get started.

This guide covers the setup process for two AI assistants: Claude and ChatGPT. At minimum, you will need to have an account with one of these assistants to use IQM MCP. If you do not have an account with either assistant, you can sign up for a free account with [Claude<ExternalLink />](https://www.anthropic.com/claude) or [ChatGPT<ExternalLink />](https://chat.openai.com/).

## Claude Setup

With Claude's Custom Connectors feature, you can connect to IQM MCP and use it directly in your Claude conversations. 

:::info
For Team and Enterprise plans, only the Owner or Primary Owner can add a Custom Connector. If you are not the Owner or Primary Owner, please reach out to your team administrator to add the IQM MCP connector for you.

See Claude's [Get started with custom connectors using remote MCP<ExternalLink />](https://support.claude.com/en/articles/11175166-get-started-with-custom-connectors-using-remote-mcp?utm_source=chatgpt.com) documentation for more information.
:::

##### Step 1: Add Custom Connector

In your Claude window navigate to **Settings > Connectors > Add > Add Custom Connector**. This will open a window where you can enter the MCP server URL and your credentials.

<center><img className='diagram' src={MCPAddConnector} /></center>

##### Step 2: Enter MCP Server URL

In the Add Customer Connector window name the connector "IQM MCP" and enter the following server URL:

```
https://mcp.iqm.com/v1/iqm/mcp
```

<center><img className='diagram' src={MCPServerUrl} /></center>

##### Step 3: Connect

Now you should see the IQM MCP connector in your list of connectors. Click **Connect** and a browser window will open asking you to log in to the IQM Platform. Enter your credentials and click **Authorize**. You will be redirected back to Claude, and the connector should now show as connected.

<center><img className='diagram' src={MCPConnect} /></center>
<p /><center><img className='diagram' src={MCPAccess} /></center>

##### Step 4: Verify Connection

After connecting, ensure that the IQM MCP connector shows as connected in Claude by navigating to **+ > Connectors**. You should see the IQM MCP connector listed as connected. You can now start using IQM MCP in your Claude conversations.

<center><img className='diagram' src={MCPEnabled} /></center>

## ChatGPT Setup

With ChatGPT's Developer Mode, you can add the IQM MCP as a custom plugin and use it directly in your ChatGPT conversations.

##### Step 1: Enable Developer Mode

In your ChatGPT window, navigate to **Settings > Security and Login > Developer Mode** and enable it. This will allow you to add custom connectors like the IQM MCP.

<center><img className='diagram' src={MCPDevMode} /></center>

##### Step 2: Add Plugin

Once Developer Mode is enabled, navigate to **Plugins** in the sidebar. On the Plugins page, click the **+** button in the top right. This will open a window where you can enter the MCP server URL and your credentials.

In the New Plugin window name the connector "IQM MCP" and enter the following server URL:

```
https://mcp.iqm.com/v1/iqm/mcp
```

Check the box "I understand and want to continue" and click **Create**. 

<center><img className='diagram' src={MCPPluginPage} /></center>
<p /><center><img className='diagram' src={MCPPlugin} /></center>

##### Step 3: Authenticate

ChatGPT will now prompt you to log in to the IQM Platform. You will be redirected to the IQM Platform login page. Click **Allow Access** and enter your credentials. You will be redirected back to ChatGPT, and the plugin should now show as connected.

<center><img className='diagram' src={MCPAddMCP} /></center>
<p /><center><img className='diagram' src={MCPAllow} /></center>

##### Step 4: Use IQM MCP

You can now use IQM MCP in your ChatGPT conversations. To do so, simply start a new conversation and select the IQM MCP plugin from the list of available plugins, or type "@iqm" to invoke the plugin. You can now ask your AI assistant to perform tasks across IQM's apps. 

<center><img className='diagram' src={MCPUse1} /></center>
<p /><center><img className='diagram' src={MCPUse2} /></center>
