# Setup Guide

## Overview

IQM Model Context Protocol (MCP) is an interface that allows AI models to access the data and functionality of the IQM platform apps. This guide covers the IQM MCP setup process for two AI assistants: Claude and ChatGPT.

## Before You Begin

Before you can use IQM MCP, you will need an account on the [IQM platform](https://app.iqm.com/). If you do not have an account, reach out to IQM Support (support@iqm.com) or your IQM representative to get started.

At a minimum, you will need to have an account with Claude or ChatGPT to use IQM MCP. If you do not have an account with either assistant, you can sign up for a free account with [Claude<ExternalLink />](https://www.anthropic.com/claude) or [ChatGPT<ExternalLink />](https://chat.openai.com/).

## Setup

### Claude Setup

With Claude's custom connectors feature, you can connect to IQM MCP and use it directly in your Claude conversations.

:::info
For Team and Enterprise plans, only the Owner or Primary Owner can add a custom connector. If you are not the Owner or Primary Owner, please reach out to your team administrator to add the IQM MCP connector for you.

See Claude's [Get started with custom connectors using remote MCP<ExternalLink />](https://support.claude.com/en/articles/11175166-get-started-with-custom-connectors-using-remote-mcp) documentation for more information.
:::

##### Step 1: Add Custom Connector

In your Claude window, navigate to **Settings > Connectors > Add > Add custom connector**. This will open the **Add custom connector** window.

<center><img className='diagram' src={MCPAddConnector} /></center>

##### Step 2: Enter MCP Server URL

In the **Add custom connector** window, name the connector "IQM MCP" and enter the following server URL:

```
https://mcp.iqm.com/v1/iqm/mcp
```

<center><img className='diagram' src={MCPServerUrl} /></center>

##### Step 3: Connect

If added correctly, the IQM MCP connector will appear in your list of connectors. If you don't see it, you can search for "IQM" in the search bar. To connect:
1. Click **Connect** and a browser window will open asking you to log in to the IQM platform. 
1. Authenticate your IQM account and click **Allow access**. 
1. You will be redirected back to Claude, and the connector should now show as connected.

<center><img className='diagram' src={MCPConnect} /></center>
<p /><center><img className='diagram' src={MCPAccess} /></center>

##### Step 4: Verify Connection

After authenticating with your IQM account, navigate to a new chat and **+ > Connectors** to ensure the IQM MCP connector is enabled. You can now start using IQM MCP in your Claude conversations.

<center><img className='diagram' src={MCPEnabled} /></center>

### ChatGPT Setup

With ChatGPT's developer mode, you can add IQM MCP as a custom plugin and use it directly in your ChatGPT conversations.

:::info
For Business, Enterprise, and Edu workspaces, a workspace admin may need to enable developer mode before you can add custom connectors. If you do not have admin access, please reach out to your workspace admin to enable developer mode for you.

See OpenAI's [Apps in ChatGPT<ExternalLink />](https://help.openai.com/en/articles/11487775-apps-in-chatgpt) documentation for more information.
:::

##### Step 1: Enable Developer Mode

In your ChatGPT window:
1. Navigate to **Settings** by clicking your account name in the bottom left corner.
1. In the Settings menu, navigate to **Security and login > Developer mode** and enable it. This will allow you to add plugins like IQM MCP.

<center><img className='diagram' src={MCPDevMode} /></center>

##### Step 2: Add Plugin

Once developer mode is enabled, navigate to **Plugins** in the sidebar. On the **Plugins** page, click the **+** button in the top right. This will open a window where you can enter the MCP server URL.

In the **New Plugin** window, name the connector "IQM MCP" and enter the following server URL:

```
https://mcp.iqm.com/v1/iqm/mcp
```

If you agree, check the box "I understand and want to continue" and click **Create**.

<center><img className='diagram' src={MCPPluginPage} /></center>
<p /><center><img className='diagram' src={MCPPlugin} /></center>

##### Step 3: Authenticate

ChatGPT will redirect you to the IQM platform login page. Authenticate your IQM account and click **Allow access**. You will be redirected back to ChatGPT, and the plugin should now show as connected.

<center><img className='diagram' src={MCPAddMCP} /></center>
<p /><center><img className='diagram' src={MCPAllow} /></center>

##### Step 4: Use IQM MCP

You can now use IQM MCP in your ChatGPT conversations. To do so, start a new conversation and either select the IQM MCP plugin from the list, or type "@iqm" to invoke the plugin. You can now ask your AI assistant to perform tasks across IQM's apps.

<center><img className='diagram' src={MCPUse1} /></center>
<p /><center><img className='diagram' src={MCPUse2} /></center>
