# Tools index

This page provides an index of the tools available within the IQM Model Context Protocol (MCP) ecosystem. Each tool allows your AI assistant to interact with different aspects of the platform, enabling you to perform tasks efficiently and effectively.

Tools are grouped below by API. Each entry includes the tool name, a brief description, and a link to the corresponding API documentation for more details on its functionality and usage.

## Asset API

The Asset API streamlines the management and storage of media files. See the [Asset tutorial](/mcp/mcp-tutorials/mcp-asset-tutorial) or the [Asset API guidelines](/guidelines/asset-api) for more information.


<AssetToolsIndex />

## Audience API

The Audience API allows you to create, manage, and target the many types of audiences available on the IQM platform. See the [Audience tutorial](/mcp/mcp-tutorials/mcp-audience-tutorial) or the [Audience API guidelines](/guidelines/audience-api) for more information.

<AudienceToolsIndex />

## Bid Model API

The Bid Model API allows you to fine-tune campaign delivery by prioritizing and adjusting spend across dimensions like Creative, Location, and Inventory. See the [Bid Model tutorial](/mcp/mcp-tutorials/mcp-bid-model-tutorial) or the [Bid Model API guidelines](/guidelines/bid-model-api) for more information.

<BidModelToolsIndex />

## Campaign API

The Campaign API allows you to create and manage campaigns, insertion orders, and their targeting settings. See the [Campaign tutorial](/mcp/mcp-tutorials/mcp-campaign-tutorial) or the [Campaign API guidelines](/guidelines/campaign-api) for more information.

<CampaignToolsIndex />

## Conversion API

The Conversion API allows you to create and manage conversions, and assign them to campaigns to track performance. See the [Conversion tutorial](/mcp/mcp-tutorials/mcp-conversion-tutorial) or the [Conversion API guidelines](/guidelines/conversion-api) for more information.

<ConversionToolsIndex />

## Creative API

The Creative API allows you to upload and manage creatives and assign them to campaigns. See the [Creative tutorial](/mcp/mcp-tutorials/mcp-creative-tutorial) or the [Creative API guidelines](/guidelines/creative-api) for more information.

<CreativeToolsIndex />

## Finance API

The Finance API allows you to manage Customer and Organization finances, including margins, invoices, payments, and credits. See the [Finance tutorial](/mcp/mcp-tutorials/mcp-finance-tutorial) or the [Finance API guidelines](/guidelines/finance-api) for more information.

<FinanceToolsIndex />

## Inventory API

The Inventory API allows you to browse Open Exchange, Contextual, Private Marketplace (PMP), and Programmatic Guaranteed (PG) inventory, and manage inventory groups and deals. See the [Inventory tutorial](/mcp/mcp-tutorials/mcp-inventory-tutorial) or the [Inventory API guidelines](/guidelines/inventory-api) for more information.

<InventoryToolsIndex />

## Reports API

The Reports API allows you to create, execute, and schedule reports on campaign performance data. See the [Reports tutorial](/mcp/mcp-tutorials/mcp-reports-tutorial) or the [Reports API guidelines](/guidelines/reports-api) for more information.

<ReportsToolsIndex />

## User Management API

The User Management API allows you to log in and out, manage user profiles and application access, and validate user credentials. See the [User management tutorial](/mcp/mcp-tutorials/mcp-user-tutorial) or the [User Management API guidelines](/guidelines/user-api) for more information.

<UserToolsIndex />

## Workspace API

The Workspace API (backed by the same underlying User Management API service) allows you to manage Organizations, Customers, and Advertisers. See the [Workspace tutorial](/mcp/mcp-tutorials/mcp-workspace-tutorial) or the [Workspace API guidelines](/guidelines/workspace-api) for more information.

<WorkspaceToolsIndex />

## Insights API

The Insights API allows you to generate Audience and Campaign Bidding Insights, and manage Voter Level Data (VLD), Script Lift Study (SLS), Audience Quality (AQ), and Provider Level Data (PLD) Insights report templates and schedules. See the [Insights tutorial](/mcp/mcp-tutorials/mcp-insights-tutorial) or the [Insights API guidelines](/guidelines/insights-api) for more information.

<InsightsToolsIndex />

## Dashboard API

The Dashboard API allows you to manage dashboards, generate campaign performance reports, and review Goal-AI optimization and CampaignPulse data. See the [Dashboard API guidelines](/guidelines/dashboard-api) for more information.

<DashboardToolsIndex />

## Master API

The Master API provides static and segment lookup data -- geographic, demographic, device, creative, and inventory reference lists -- used to populate targeting options across the platform. See the [Master API guidelines](/guidelines/master-api) for more information.

<MasterToolsIndex />

## Planner API

The Planner API allows you to draft ad strategy proposals and plans, including Political and Healthcare Professional (HCP) Planner workflows, and generate insertion orders and campaigns from them. See the [Planner API guidelines](/guidelines/planner-api) for more information.

<PlannerToolsIndex />
