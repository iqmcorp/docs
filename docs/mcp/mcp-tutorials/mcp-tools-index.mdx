# Tools Index

This page provides an index of the tools available within the IQM Model Context Protocol (MCP) ecosystem. Each tool allows your AI assistant to interact with different aspects of the platform, enabling you to perform tasks efficiently and effectively.

Tools are grouped below by API. Each entry includes the tool name, a brief description, and a link to the corresponding API documentation for more details on its functionality and usage.

## Assets API

The Asset API streamlines the management and storage of media files. See the [Assets Tutorial](/mcp/mcp-tutorials/mcp-asset-tutorial) or the [Assets API Guidelines](/guidelines/asset-api) for more information.

<AssetToolsIndex />

## Audience API

The Audience API allows you to create, manage, and target the many types of Audiences available on the IQM platform. See the [Audience Tutorial](/mcp/mcp-tutorials/mcp-audience-tutorial) or the [Audience API Guidelines](/guidelines/audience-api) for more information.

<AudienceToolsIndex />

## Bid Model API

The Bid Model API allows you to fine-tune Campaign delivery by prioritizing and adjusting spend across dimensions like Creatives, Location, and Inventory. See the [Bid Model Tutorial](/mcp/mcp-tutorials/mcp-bid-model-tutorial) or the [Bid Model API Guidelines](/guidelines/bid-model-api) for more information.

<BidModelToolsIndex />

## Campaign API

The Campaign API allows you to create and manage Campaigns, Insertion Orders, and their targeting settings. See the [Campaign Tutorial](/mcp/mcp-tutorials/mcp-campaign-tutorial) or the [Campaign API Guidelines](/guidelines/campaign-api) for more information.

<CampaignToolsIndex />

## Conversion API

The Conversion API allows you to create and manage Conversions, and assign them to Campaigns to track performance. See the [Conversion Tutorial](/mcp/mcp-tutorials/mcp-conversion-tutorial) or the [Conversion API Guidelines](/guidelines/conversion-api) for more information.

<ConversionToolsIndex />

## Creative API

The Creative API allows you to upload and manage Creatives and assign them to Campaigns. See the [Creative Tutorial](/mcp/mcp-tutorials/mcp-creative-tutorial) or the [Creative API Guidelines](/guidelines/creative-api) for more information.

<CreativeToolsIndex />

## Finance API

The Finance API allows you to manage Customer and Organization finances, including margins, invoices, payments, and credits. See the [Finance Tutorial](/mcp/mcp-tutorials/mcp-finance-tutorial) or the [Finance API Guidelines](/guidelines/finance-api) for more information.

<FinanceToolsIndex />

## Inventory API

The Inventory API allows you to browse Open Exchange, Contextual, PMP, and PG inventory, and manage Inventory Groups and Deals. See the [Inventory Tutorial](/mcp/mcp-tutorials/mcp-inventory-tutorial) or the [Inventory API Guidelines](/guidelines/inventory-api) for more information.

<InventoryToolsIndex />

## Reports API

The Reports API allows you to create, execute, and schedule Reports on Campaign performance data. See the [Reports Tutorial](/mcp/mcp-tutorials/mcp-reports-tutorial) or the [Reports API Guidelines](/guidelines/reports-api) for more information.

<ReportsToolsIndex />

## User API

The User API allows you to log in and out, manage user profiles and application access, and validate user credentials. See the [User Management Tutorial](/mcp/mcp-tutorials/mcp-user-tutorial) or the [User API Guidelines](/guidelines/user-api) for more information.

<UserToolsIndex />

## Workspace API

The Workspace API (backed by the same underlying User API service) allows you to manage Organizations, Customers, and Advertisers. See the [Workspace Tutorial](/mcp/mcp-tutorials/mcp-workspace-tutorial) or the [Workspace API Guidelines](/guidelines/workspace-api) for more information.

<WorkspaceToolsIndex />

## Insights API

The Insights API allows you to generate Audience and Campaign Bidding Insights, and manage VLD, SLS, AQS, and PLD report templates and schedules. See the [Insights Tutorial](/mcp/mcp-tutorials/mcp-insights-tutorial) or the [Insights API Guidelines](/guidelines/insights-api) for more information.

<InsightsToolsIndex />

## Dashboard API

The Dashboard API allows you to manage Dashboards, generate Campaign performance reports, and review Goal-AI optimization and Campaign Pulse data. See the [Dashboard API Guidelines](/guidelines/dashboard-api) for more information.

<DashboardToolsIndex />
