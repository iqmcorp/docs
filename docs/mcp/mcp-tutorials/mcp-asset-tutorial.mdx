# MCP assets tutorial

Use IQM Model Context Protocol (MCP) to interact with the Asset API.

## Overview

This tutorial guides you through using IQM MCP to access and manage assets with the Asset API. You'll learn how to retrieve asset details, upload new assets, and update existing assets using the MCP interface.

## Before you begin

To upload an asset using IQM MCP, the following are required:

1. An account on the IQM platform
   *  See [Before you begin](/getting-started/before-you-begin) to create an account and request a Client ID and Client Secret
1. A file to upload as an asset (image, video, audio, document, or ZIP)

## About IQM assets

The Asset API streamlines the management and storage of media files. This service plays a critical role in handling media uploads, temporary storage, and coordination with other services for final storage and metadata management.
