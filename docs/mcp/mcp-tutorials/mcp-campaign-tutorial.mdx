# MCP campaign tutorial

Use IQM Model Context Protocol (MCP) to interact with the Campaign API.

## Overview

This tutorial guides you through using IQM MCP to access and manage campaigns and insertion orders (IOs) with the Campaign API.

The Campaign MCP supports a limited set of features of the Campaign API. For a comprehensive list of supported features and best practices for using the Campaign API, refer to the [Campaign API guidelines](/guidelines/campaign-api).

## Before you begin

To create an IO and campaign, the following are required:

1. An account on the IQM platform
   *  See [Before you begin](/getting-started/before-you-begin) to create an account and request a Client ID and Client Secret
1. An approved and running creative 
   * See [MCP creative tutorial - Upload a creative](/mcp/mcp-tutorials/mcp-creative-tutorial/#upload-a-creative)
1. A conversion
   * See [MCP conversion tutorial - Create a conversion](/mcp/mcp-tutorials/mcp-conversion-tutorial/#create-a-conversion)
1. A PG deal (for PG campaigns)
   * See [Create a deal](/tutorials/deal-guide) tutorial

## About IQM campaigns

IQM's campaigns define the individual marketing strategies of your ads. By specifying the supported parameters, you can use the API to create a new campaign.
