# MCP Insights tutorial

Use IQM Model Context Protocol (MCP) to interact with the Insights API. 

## Overview

This tutorial guides you through using IQM MCP to generate Insights reports and templates. 

## Before you begin

To manage Insights reports using IQM MCP, the following are required:

1. An account on the IQM platform
   *  See [Before you begin](/getting-started/before-you-begin) to create an account and request a Client ID and Client Secret
1. IQM MCP set up on your computer
   * See the MCP [Setup guide](/mcp/mcp-getting-started/setup-guide/) to set up MCP with your authorization credentials
1. An audience and campaign that meet the eligibility requirements for generating Insights reports
   * [Audience Insights - Create Audience Insights report](/guidelines/insights-api/#create-audience-insights-report)
   * [Audience Quality reports - AQ Insights report eligibility requirements](/guidelines/insights-api/#aq-insights-report-eligibility-requirements)
   * [Voter Level Data reports - VLD Insights eligibility requirements](/guidelines/insights-api/#vld-insights-eligibility-requirements)
   * [Script Lift Study reports - SLS Insights eligibility requirements](/guidelines/insights-api/#sls-insights-eligibility-requirements)
   * [Report templates - PLD Insights eligibility requirements](/guidelines/insights-api/#pld-insights-eligibility-requirements)
   * [Report templates - NLD Insights eligibility requirements](/guidelines/insights-api/#nld-insights-eligibility-requirements)
   * [Report templates - ICT Insights eligibility requirements](/guidelines/insights-api/#ict-insights-eligibility-requirements)

## About IQM Insights

Insights reports are one of IQM's analytics tools that help Advertisers quickly identify trends and apply precise adjustments to deliver better results for campaigns. 

With pre-defined metrics and dimensions, Insights reports can be generated for the following areas:


<table class ="definitionsTableNotes">
<th>Type</th>
<th>Description</th>
<tr>
<td><b>Campaign Bidding Insights</b></td>
<td>Campaign Bidding Insights capture rejected campaigns and segment them based on rejection reason, allowing you to assess which parameters are limiting a campaign's success.</td>
</tr>
<tr>
<td><b>Audience Insights</b></td>
<td>Audience Insights provide in-depth reports of audience characteristics, interests, and behaviors to give you a deeper understanding of your target audience and create targeted and personalized advertising strategies.</td>
</tr>
<tr>
<td><b>Audience Quality</b> (AQ)</td>
<td>AQ Insights leverage third-party healthcare data from PurpleLab to confirm audience exposure based on patient-level targeting criteria including prescriptions, diagnoses, and procedures.</td>
</tr>
<tr>
<td><b>Voter Level Data</b> (VLD)</td>
<td>VLD Insights offer Insights about targeting in current or prior political campaigns. These reports include ad exposure, engagement data, demographic data, and voting-history details by voter.</td>
</tr>
<tr>
<td><b>Script Lift Study</b> (SLS)</td>
<td>SLS Insights include key details about prescribing behaviors and how they're influenced by current and previous healthcare campaigns.</td>
</tr>
<tr>
<td><b>Provider Level Data</b> (PLD)</td>
<td>PLD Insights include details about healthcare professionals targeted in your campaigns, and provide similar details as VLD Insights while adhering to healthcare data privacy regulations.</td>
</tr>
<tr>
<td><b>Nurse Level Data</b> (NLD)</td>
<td>NLD Insights offer deeper visibility into how Non-NPI nurses engage with your campaigns. They uncover ad-exposure, engagement, demographic, and physician-specialty data to reveal reach and impact.</td>
</tr>
<tr>
<td><b>Integrated Care Team</b> (ICT)</td>
<td>ICT Insights uncover key details about the <a href="/healthcare-vertical/audience-healthcare/#ict-audiences">ICT audiences</a> you've targeted in previous and current campaigns.</td>
</tr>
</table>

<div style={{ maxWidth: "1000px" }}>
:::warning[NOTE]
Some Insights reports need to be enabled by an administrator before you can access them. By default, VLD, PLD, SLS, and AQ reports are not accessible to advertiser users. 

You can check an advertiser's access to Insights reports with the [Get Customer Config Details](/guidelines/workspace-api/#get-customer-config-details) endpoint. 
:::
</div>
