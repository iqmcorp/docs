# Migrate a Bid Model

Migrate a Bid Model from Beeswax to IQM by comparing each platform's API methods for creating and managing Bid Model settings.

The definitions and API comparison tables highlight the shared terminology, actions and API methods between IQM and Beeswax for creating and managing Bid Model settings. Select an endpoint to review each platform's relevant API documentation. By comparing APIs, you can migrate your workflow from Beeswax to IQM. 

For a comprehensive overview of IQM's Bid Model services, see the [Bid Model API](/guidelines/bid-model-api) guidelines.
