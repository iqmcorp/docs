# Finance API

This page covers the methods and endpoints associated with finance operations. With the Finance API you can access and manage PLD, SLS, and AQ Insights report fees. 

<div class="definitionsTable">
  | Type | Vertical |
  | --- | --- |
  | **Voter Level Data (VLD) Insights report** | Political vertical
  | **Provider Level Data (PLD) Insights report** | Healthcare vertical
  | **Script Lift Study (SLS) Insights report** | Healthcare vertical
  | **AQ Insights report** | Healthcare vertical
  | **Integrated Care Team (ICT) Insights report** | Healthcare vertical
  | **Nurse Level Data (NLD) Insights report** | Both Political and Healthcare verticals
</div>
