# Insights API

Insights reports are one of IQM's analytics tools that help Advertisers quickly identify trends and apply precise adjustments to deliver better results for campaigns. With pre-defined metrics and dimensions, Insights reports can be generated for Provider Level Data (PLD) Insights and Script Lift Study (SLS) Insights. 

<table class ="definitionsTableNotes">
<th>Type</th>
<th>Description</th>
<th>Notes</th>
<tr>
<td><b>Audience Quality (AQ) Insights report</b></td>
<td>AQ Insights reports leverage third-party healthcare data from PurpleLab to confirm audience exposure based on patient-level targeting criteria including prescriptions, diagnoses, and procedures.</td>
</tr>
<tr>
<td><b>Script Lift Study (SLS) Insights report</b></td>
<td>SLS Insights reports include key details about prescribing behaviors and how they are influenced by current and previous Healthcare campaigns.</td>
</tr>
<tr>
<td><b>Provider Level Data (PLD) Insights report</b></td>
<td>PLD Insights reports include details about healthcare professionals targeted in your campaigns, and provide similar details as VLD Insights reports while adhering to healthcare data privacy regulations.</td>
<td rowSpan="3">PLD Insights, NLD Insights, and ICT Insights reports are handled by the [Report templates](#report-templates) endpoints with the <var>category</var> parameter.</td>
</tr>
<tr>
<td><b>Nurse Level Data (NLD) Insights report</b></td>
<td>NLD Insights reports offer deeper visibility into how Non-NPI nurses engage with your campaigns. They uncover ad-exposure, engagement, demographic, and physician-specialty data to reveal reach and impact.</td>
</tr>
<tr>
<td><b>Integrated Care Team (ICT) Insights report</b></td>
<td>ICT Insights reports uncover key details about the <a href="/healthcare-vertical/audience-healthcare/#ict-audiences">ICT audiences</a> you’ve targeted in previous and current campaigns.</td>
</tr>
</table>

<div style={{ maxWidth: "1000px" }}>
:::warning[NOTE]
Some Insights reports will need to be enabled by an administrator to access. By default PLD, SLS, and AQ Insights reports are not accessible to Advertiser users. 

You can check an Advertiser's access to Insights reports with the [Get Customer config details](/guidelines/workspace-api/#get-customer-config-details) endpoint. 
:::
</div>
