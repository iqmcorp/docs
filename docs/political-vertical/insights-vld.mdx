# Insights API

Insights reports are one of IQM's analytics tools that help Advertisers quickly identify trends and apply precise adjustments to deliver better results for campaigns. With pre-defined metrics and dimensions, Insights reports can be generated for Power Segment Insights and Voter Level Data (VLD) Insights. 

**Power Segment Insights** (PSI) reports offer audience Insights for pre-defined political personality segments, such as office-holders, candidates, and other public figures.

**Voter Level Data (VLD) Insights** reports offer information about targeting in current or prior political campaigns. These reports include ad exposure, engagement data, demographic data, and voting-history details by voter.

<div style={{ maxWidth: "1000px" }}>
:::warning[NOTE]
Some Insights reports will need to be enabled by an administrator to access. By default VLD Insights reports are not accessible to Advertiser users. 

You can check an Advertiser's access to Insights reports with the [Get Customer config details](/guidelines/workspace-api/#get-customer-config-details) endpoint. 
:::
</div>
