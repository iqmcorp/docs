### Targeting Consistency Rule

The values selected in <var>planLevelTargeting</var> and each <var>audienceBlocks</var> entry must agree with
the corresponding <var>splitStrategy[].selectedValueIds</var> entry and with every <var>campaigns[].targeting</var>
value actually used. This applies across 5 dimensions. A mismatch on any dimension is rejected
with a generic error that does not say which field disagreed, so it's worth getting these
right before submitting.

For each dimension you split on, the matching <var>splitStrategy[]</var> entry's <var>selectedValueIds</var>
must exactly match both sides of the table above: the plan-level selection and every value
actually used in <var>campaigns[]</var>.

<table className="targetingRuleTable">
<tr>
<td>Dimension: <var>splitDimensionType.id</var></td>
<td>Must equal <var>planLevelTargeting</var> / <var>audienceBlocks</var></td>
<td>Must equal <var>campaigns[].targeting</var></td>
</tr>
<tr>
<td>Creative: <var>1</var></td>
<td><var>planLevelTargeting.creativeTypes.creativeTypeIds</var> (all real Creative type IDs when <var>allCreativeTypesSelected</var> is <var>true</var>, otherwise the explicit list)</td>
<td><var>creativeTypeId</var> <span class="type-text">(singular)</span></td>
</tr>
<tr>
<td>NPI: <var>2</var></td>
<td>Top-level <var>npiTypeIds</var></td>
<td><var>npiTypeId</var> <span class="type-text">(singular)</span></td>
</tr>
<tr>
<td>Partner: <var>3</var></td>
<td>The set of <var>dataPartners[].id</var> across all <var>audienceBlocks</var></td>
<td><var>dataPartnerIds</var></td>
</tr>
<tr>
<td>Device: <var>4</var></td>
<td><var>planLevelTargeting.devices.deviceTypeIds</var> (all real device type IDs when <var>allDeviceTypesSelected</var> is <var>true</var>, otherwise the explicit list)</td>
<td><var>deviceTypeIds</var></td>
</tr>
<tr>
<td>Audience Type: <var>5</var></td>
<td>The union of <var>selectedAudienceTypeIds</var> across all <var>audienceBlocks</var></td>
<td><var>audienceTypeIds</var></td>
</tr>
</table>

### Generate Campaigns Plan
