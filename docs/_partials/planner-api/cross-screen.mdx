### Get reach saturation graph

<CopyUrl method="POST" url="https://api.iqm.com/api/v3/plan/political/reach-saturation-graph" operationId="getCrossScreenGraph" />

<div class="endpoint-container">
  <div class="child1">

Fetch cross-screen Planner graph data based on the targeting and budgeting criteria provided, including a Venn-diagram audience overlap breakdown and a line graph of linear TV and CTV reach over time.

To adjust the forecast, call this endpoint again with the same <var>graphId</var> and new <var>overview</var> values. Use the <var>graphId</var> and <var>overview</var> from the response to [create a Voter TV+ plan](#create-plan).

If <var>audienceOverlap.totalReach</var> is <var>0</var>, a plan created from the graph produces a proposal with <var>0</var> budgets. Narrow the location targeting, for example to states or DMAs, and request a new graph.

:::info
The first request for a new graph calls an external data service and can take more than 60 seconds. Allow sufficient time for the request to complete. Later requests with the same <var>graphId</var> are calculated without the external call.
:::

### Get demographics keys

<CopyUrl method="GET" url="https://api.iqm.com/api/v3/plan/political/static/demographics" operationId="getDemographicsKeyData" />

<div class="endpoint-container">
  <div class="child1">

Get active demographics segment definitions used for cross-screen planning audience mapping (e.g. age, gender, income, and ethnicity groupings). Call without <var>parentIds</var> to get the top-level segment keys (categories like <var>Age Group</var>, <var>Income Level</var>). Call with <var>parentIds</var> set to one or more of those keys' <var>id</var>s to get the specific demographics values nested under them (e.g. <var>65+</var> under <var>Age Group</var>), each with its own <var>parentId</var>, <var>reach</var>, and display <var>order</var>.

| Query parameters |  |
| ---- | --- |
| `parentIds` <br /><span class="type-text">array of integers</span> | Segment key <var>id</var>s to fetch demographics values for. Omit to get the top-level segment keys instead. |

Split a Voter TV+ proposal's CTV campaigns into one campaign per value of a targeting dimension, such as one campaign per state. Only works for cross-screen proposals with a [plan objective ID](#get-plan-objectives) of <var>3</var>. The existing CTV campaigns are replaced. Send an empty <var>locations</var> list to merge them back into a single CTV campaign.

A split only has an effect for dimensions that the plan targets with more than one value. Split campaigns are named with a numbered suffix, such as <var>_Video + Loc_1</var> and <var>_Loc_2</var>.

:::info
Computation time for this endpoint may take more than 60 seconds depending on the complexity of the targeting criteria and the size of the proposal being split. Please allow for sufficient time for the request to complete.
:::

| Path parameters |  |
| ---- | --- |
| `proposalId` <br /><span class="type-text">integer</span> <span class="required-text">required</span> | [Proposal ID](#get-list-of-proposals) to split. |

| Request schema |  |
| ---- | --- |
| `splitTypeId` <br /><span class="type-text">integer</span> | [Split type ID](#get-split-types). <br /><EnumWidget values={splitTypes} /> |
| `locations` <br /><span class="type-text">array of integers</span> | [Targeting type IDs](#get-targeting-types) to split by. These are targeting dimension IDs, not location IDs, for example <var>8</var> (state), <var>12</var> (DMA), <var>15</var> (ZIP code), or <var>29</var> (device). <br /><EnumWidget values={targetingTypes} /> |
| `devices` <br /><span class="type-text">array of integers</span> | [Device type IDs](/guidelines/master-api/#get-device-type). <br /><EnumWidget values={deviceType} /> |
| `inventoryGroupIds` <br /><span class="type-text">array of integers</span> | [Inventory group IDs](/guidelines/inventory-api/#get-inventory-groups-list). |
| `audienceTypes` <br /><span class="type-text">array of integers</span> | [Audience type IDs](/guidelines/audience-api/#audience-type-list). <br /><EnumWidget values={audienceTypes} /> |
| `creatives` <br /><span class="type-text">array of integers</span> | [Creative type IDs](/guidelines/creative-api/#get-creative-types-list). <br /><EnumWidget values={creativeTypes} /> |

Returns the proposal details as they were before the split. To see the new campaigns, call [Get proposal details](#get-proposal-details).
