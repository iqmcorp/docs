### Get demographics keys

<CopyUrl method="GET" url="https://api.iqm.com/api/v3/plan/political/static/demographics" operationId="getDemographicsKeyData" />

<div class="endpoint-container">
  <div class="child1">

Get active demographics segment definitions used for cross-screen planning audience mapping (e.g. age, gender, income, and ethnicity groupings). Call without <var>parentIds</var> to get the top-level segment keys (categories like `Age Group`, `Income Level`). Call with <var>parentIds</var> set to one or more of those keys' <var>id</var>s to get the specific demographics values nested under them (e.g. `65+` under `Age Group`), each with its own <var>parentId</var>, <var>reach</var>, and display <var>order</var>.

| Query parameters |  |
| ---- | --- |
| `parentIds` <br /><span class="type-text">array of integers</span> | Segment key <var>id</var>s to fetch demographics values for. Omit to get the top-level segment keys instead. |

<details className="objectPropertiesDetails" style={{ maxWidth: "800px", padding: "1rem" }}>
  <summary style={{ fontSize: "16px" }}>Response properties</summary>
<table className="objectProperties">
<tr>

  <td>Demographics segment ID.</td>
</tr>
<tr>
  <td>`segmentId` <br /><span class="type-text">integer</span></td>
  <td>Segment ID used for audience targeting.</td>
</tr>
<tr>
  <td>`name` <br /><span class="type-text">string</span></td>
  <td>Segment display name.</td>
</tr>
<tr>
  <td>`parentId` <br /><span class="type-text">integer</span></td>
  <td><var>id</var> of the parent segment key. Only present when <var>parentIds</var> was supplied in the request.</td>
</tr>
<tr>
  <td>`reach` <br /><span class="type-text">integer</span></td>
  <td>Reach for this demographics value. Only present when <var>parentIds</var> was supplied in the request.</td>

  <td>`order` <br /><span class="type-text">integer</span></td>
  <td>Display order of this demographics value. Only present when <var>parentIds</var> was supplied in the request.</td>
</tr>
</table>
</details>

### Split proposal

<CopyUrl method="POST" url="https://api.iqm.com/api/v3/plan/political/proposals/{proposalId}/split" operationId="splitProposal" />

<div class="endpoint-container">
  <div class="child1">

Split an existing proposal across linear TV and CTV using the provided advanced targeting criteria. Only works for cross-screen proposals with a [plan objective ID](#get-plan-objectives) of <var>3</var>.

:::info
Computation time for this endpoint may take more than 60 seconds depending on the complexity of the targeting criteria and the size of the proposal being split. Please allow for sufficient time for the request to complete.
:::

| Path parameters |  |
| ---- | --- |
| `proposalId` <br /><span class="type-text">integer</span> <span class="required-text">required</span> | [Proposal ID](#get-list-of-proposals) to split. |

| Request schema |  |
| ---- | --- |
| `splitTypeId` <br /><span class="type-text">integer</span> | [Split type ID](#get-split-types). <br /><EnumWidget values={splitTypes} /> |
| `locations` <br /><span class="type-text">array of integers</span> | [Targeting type IDs](#get-targeting-types) for locations. <br /><EnumWidget values={targetingTypes} /> |
| `devices` <br /><span class="type-text">array of integers</span> | [Device type IDs](/guidelines/master-api/#get-device-type). <br /><EnumWidget values={deviceType} /> |
| `inventoryGroupIds` <br /><span class="type-text">array of integers</span> | [Inventory group IDs](/guidelines/inventory-api/#get-inventory-groups-list). |
| `audienceTypes` <br /><span class="type-text">array of integers</span> | [Audience type IDs](/guidelines/audience-api/#audience-type-list). <br /><EnumWidget values={audienceTypes} /> |
| `creatives` <br /><span class="type-text">array of integers</span> | [Creative type IDs](/guidelines/creative-api/#get-creative-types-list). <br /><EnumWidget values={creativeTypes} /> |

Returns the updated proposal, in the same shape as [Get proposal details](#get-proposal-details).
