:::info

Power Segment Insights (PSI) is available to political vertical Advertisers only. All PSI endpoints return a `403` for non-political Organizations.

:::

### Generate PSI Report

<CopyUrl method="POST" url="https://api.iqm.com/api/v3/ins/psi/generate-report" />

<div class="endpoint-container">
  <div class="child1">

Initiates report generation for a power segment identified by its <var>taxonomyId</var>. The request is forwarded to the data team after validating the segment's current report status.

Only segments with a <var>status</var> of <var>NotRequested</var> or <var>Failed</var> can be triggered. 

See [Get Power Segment Insights List](#get-power-segment-insights-list).

| Request Schema |  |
| ---- | --- |
| `taxonomyId` <br /><span class="type-text">string</span> | [Taxonomy ID](#get-power-segment-insights-list) of the power segment |

  <details className="objectPropertiesDetails" style={{ maxWidth: "100%", padding: "1rem" }}>
    <summary style={{fontSize: "16px"}}>Response Properties</summary>
    <table className="objectProperties">
    <tr>
    <td>`message` <br /><span class="type-text">string</span></td>
    <td>Success message</td>
    </tr>
    </table>
    </details>

</div><div class="child2">

<Tabs>
<TabItem value="JSON" label="JSON" default>

```json title="Request Sample"
{
  "taxonomyId": "IQMADV0002606"
}
```

```json title="Response 200"
{
  "success": true,
  "data": {
    "message": "Report generation initiated successfully."
  }
}
```

```json title="Response 422 (report already in progress or ready)"
{
  "success": false,
  "errorObjects": [
    {
      "error": "Report generation cannot be initiated. Current report status is: Processing"
    }
  ]
}
```

</TabItem>
<TabItem value="TypeScript" label="TypeScript">

See [TypeScript Prerequisites](/getting-started/typescript-prerequisites.mdx) for usage.

```ts
import {
  getInstance
} from "prerequisites"

const axios = getInstance();

interface Responses {
  200: {
    content: {
      "application/json": {
        success: boolean;
        data: {
          message: string;
        }
      }
    };
  };
};

function generatePsiReport(): Promise<Responses> {
  const options = {
    method: 'POST',
    url: 'https://api.iqm.com/api/v3/ins/psi/generate-report',
    requestBody: {
      content: {
        "application/json": {
          taxonomyId: `string`,
        }
      }
    }
  };
  
  return axios.request(options).then(({ data }: { data: Responses }) => data);
}
```

### Email PSI Report

<CopyUrl method="POST" url="https://api.iqm.com/api/v3/ins/psi/email" />

<div class="endpoint-container">
  <div class="child1">

Sends the PSI Report PDF for the given <var>taxonomyId</var> to the specified email addresses. If the file is 10 MB or smaller the PDF is attached directly; otherwise the email includes a download link only. The report must be in <var>Ready</var> status.

| Query Parameters |  |
| ---- | --- |
| `taxonomyId` <br /><span class="type-text">string</span> <span class="required-text">required</span> | [Taxonomy ID](#get-power-segment-insights-list) of the power segment |

| Request Schema |  |
| ---- | --- |
| `emailIds` <br /><span class="type-text">array of strings</span> | Email addresses to send the report to, 1-15 addresses, each 1-320 characters |

  <details className="objectPropertiesDetails" style={{ maxWidth: "100%", padding: "1rem" }}>
    <summary style={{fontSize: "16px"}}>Response Properties</summary>
    <table className="objectProperties">
    <tr>
    <td>`message` <br /><span class="type-text">string</span></td>
    <td>Success message</td>
    </tr>
    </table>
    </details>

</div><div class="child2">

<Tabs>
<TabItem value="JSON" label="JSON" default>

```json title="Request Sample"
{
  "emailIds": ["jane.doe@example.com"]
}
```

```json title="Response 200"
{
  "success": true,
  "data": {
    "message": "Report email sent successfully."
  }
}
```

```json title="Response 422 (report not ready)"
{
  "success": false,
```
