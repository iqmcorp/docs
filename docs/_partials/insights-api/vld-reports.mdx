### VLD Insights eligibility requirements

VLD Insights reports are available for campaigns that meet certain requirements. 

Read more about these requirements in our [Help Center<ExternalLink />](https://help.iqm.com/en/articles/9827089-voter-level-data-vld-insights-report-overview#h_f7f335080d) article.

<table className="requirementsTable">
<th>Requirement type</th>
<th>Requirement details</th>
<th>Notes</th>
<tr>
  <td>Campaign vertical</td>
  <td>Political</td>
  <td>Any campaign created under a Political Advertiser account is a “Political” campaign.</td>
</tr>
<tr>
  <td>Campaign status</td>
  <td>Running, Expired (within the past two years), Paused</td>
</tr>
<tr>
  <td>Campaign duration</td>
  <td>3 or more days</td>
</tr>
<tr>
  <td>Campaign creation date</td>
  <td>September 16, 2024 or later (or earlier upon request to IQM's support team)</td>
</tr>
<tr>
  <td>Voter location</td>
  <td>All US states except Oregon</td>
  <td>Due to privacy laws in the state of Oregon, we are unable to generate the VLD Insights report on any voters located there. Contact your account representative for more detailed information on the legality of reidentifying voters at the user level.</td>
</tr>
<tr>
  <td>Audience type</td>
  <td>Matched audience created from L2 IDs, Matched audience created from raw data</td>
  <td>Your campaign must only include the audience types listed in this requirements table. For example, you cannot generate a VLD Insights report for a campaign if it includes a Matched audience created from L2 IDs and a Retargeted audience consisting of your website’s past visitors. <p />The VLD Insights report supports audiences you create using First Name, Last Name, Address, and Phone Number. IQM anonymizes the data in the matching process, encrypts the files, and stores them behind a firewall to protect them against information leaks.</td>
</tr>
</table>

### Generate VLD Insights report

<CopyUrl method="POST" url="https://api.iqm.com/api/v3/ins/vld-report" />

<div class="endpoint-container">
  <div class="child1">

This endpoint calculates the cost for the impressions for the VLD Insights reports based on the impressions and mark up charged on the Organization and then creates the VLD Insights reports.

:::info 

A campaign must meet the following eligibility criteria to generate VLD Insights report: 
  * Must be Political campaign 
  * "running," "expired" (within last two years), "paused" status
  * Must have duration of 3 or more days
  * Creation date: Sept. 16, 2024 or later
  * Voter location: all US states (except Oregon)
  * Audience type: **Matched audience**

:::

| Request schema |  |
| ---- | --- |
| `vldStartDate` <br /><span class="type-text">integer</span> | Unix epoch timestamp of start date, in milliseconds |
| `vldEndDate` <br /><span class="type-text">integer</span> | Unix epoch timestamp of end date, in milliseconds |
| `campaignId` <br /><span class="type-text">integer</span> | [Campaign ID](/guidelines/campaign-api#get-list-of-campaigns) |
| `vldId` <br /><span class="type-text">integer</span> | Generate Insights report again for [VLD Insights ID](#get-list-of-vld-insights-reports)
