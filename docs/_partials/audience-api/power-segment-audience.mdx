  <div class="child1">

### List/search Power Segments

<CopyUrl method="POST" url="https://api.iqm.com/api/v3/audience/power-segment/segments/search/list" operationId="getPowerSegmentSearchList" />

<div class="endpoint-container">
  <div class="child1">

Search and filter Power Segments. 

The <var>individual</var> tab shows active standard segments plus the caller's org's private active segments; the <var>requested</var> tab shows only the caller's org's private segments that are active, requested, or failed. Favorite status is resolved for the logged-in user.

| Request schema | |
| --- | --- |
| `pageNo` <br /><span class="type-text">integer</span> | Page number of retrieved data. |
| `noOfEntries` <br /><span class="type-text">integer</span> | Number of entries returned per page. |

| `taxonomyIds` <br /><span class="type-text">array of strings</span> | When provided, restricts results to personalities owning any of these Sphere or Orbit taxonomy IDs. Max 100. |

### Request a custom Power Segment

<CopyUrl method="POST" url="https://api.iqm.com/api/v3/audience/power-segment/segments/request" operationId="createPowerSegmentRequest" />

<div class="endpoint-container">
  <div class="child1">

Submits a custom Power Segment request for a personality, private to the logged-in organization. One segment is created per requested <var>segmentType</var> with status <var>requested</var>. 

If only <var>orbit</var> is requested, a <var>deleted</var> Sphere segment is also created for the personality; if only <var>sphere</var> is requested, no Orbit segment is created. Political vertical advertiser users only.

| Request schema | |
| --- | --- |
| `personalityName` <br /><span class="type-text">string</span> <span class="required-text">required</span> | Name of the personality the segment is requested for. |
| `segmentType` <br /><span class="type-text">array of strings</span> <span class="required-text">required</span> | Segment types requested for the personality (case-insensitive): <var>sphere</var>, <var>orbit</var>, or both. |
| `additionalDetails` <br /><span class="type-text">string</span> <span class="required-text">required</span> | Free-text details to help fulfil the request. |

<details className="objectPropertiesDetails" style={{ maxWidth: "800px", padding: "1rem" }}>
