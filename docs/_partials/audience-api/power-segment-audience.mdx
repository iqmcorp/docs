### Create Power Segment audience

<CopyUrl method="POST" url="https://api.iqm.com/api/v3/audience/power-segment" operationId="createPowerSegmentAudience" />

<div class="endpoint-container">
  <div class="child1">

Create a Power Segment audience. Only available to advertisers under the Political vertical.

| Request schema | |
| --- | --- |
| `audienceName` <br /><span class="type-text">string</span> <span class="required-text">required</span> | Audience name. |
| `equation` <br /><span class="type-text">string</span> <span class="required-text">required</span> | Equation representing the combination of [Power Segment taxonomy IDs](#listsearch-power-segments), using taxonomy IDs and the OR operator (`\|`), wrapped in a double set of parentheses. Every taxonomy ID must belong to an active segment that is either a standard segment or private to the logged-in organization. |

<details className="objectPropertiesDetails" style={{ maxWidth: "800px", padding: "1rem" }}>
  <summary style={{ fontSize: "16px" }}>Response properties</summary>
  <table className="objectProperties">
  <tr>
    <td>`audienceId` <br /><span class="type-text">integer</span></td>
    <td>[Audience ID](/guidelines/audience-api#audience-details-list).</td>
  </tr>
  <tr>
    <td>`message` <br /><span class="type-text">string</span></td>
    <td>Success message.</td>
  </tr>
  </table>
</details>

</div>
