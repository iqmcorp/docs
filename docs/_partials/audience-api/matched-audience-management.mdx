### Create Matched audience

<CopyUrl method="POST" url="https://api.iqm.com/api/v3/audience/matched" operationId="createMatchedAudience_1" />

<div class="endpoint-container">
  <div class="child1">

Create a Matched audience by uploading a file with user data. The metadata is sent as a JSON string in the <var>audienceRequest</var> form data field, and the file is uploaded as multipart/form-data in the <var>file</var> form data field.

For more information on Matched audiences and how they can serve your Healthcare, Political, or Specialty needs, refer to our [Help Center<ExternalLink />](https://help.iqm.com/en/articles/11535636-matched-audience-overview) articles.

| Request schema | |
| --- | --- |
| `audienceRequest` <br /><span class="type-text">form data</span> <span class="required-text">required</span> | Audience metadata details.
| `file` <br /><span class="type-text">multipart/form-data</span> <span class="required-text">required</span> | File to be uploaded.

### Update Matched audience

<CopyUrl method="PATCH" url="https://api.iqm.com/api/v3/audience/matched/{audienceId}" operationId="updateMatchedAudience" />

<div class="endpoint-container">
  <div class="child1">

Update a Matched audience. 

| Path parameter | |
| --- | --- |
| `audienceId` <br /><span class="type-text">integer</span> | [Matched audience ID](/guidelines/audience-api/#audience-details-list).

| Request schema | |
| --- | --- |
| `dataCost` <br /><span class="type-text">number</span> | Data cost.
| `audienceStatusId` <br /><span class="type-text">integer</span> | [Audience status ID](/guidelines/audience-api/#audience-status-list). <br /><EnumWidget values={audienceStatuses} />
| `rejectionReason` <br /><span class="type-text">string</span> | Reason for rejection if updating status to <var>Rejected</var>.
