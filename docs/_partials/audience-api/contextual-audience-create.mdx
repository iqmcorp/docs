<div class="endpoint-container">

Create a Contextual audience. 

Data collection period: the timeframe during which a user visits the publisher(s) relevant to one or more keywords or URLs added to the Contextual audience. 

:::info 

The start date of a Contextual audience must be within the last 180 days. 

Contextual audiences support a static or dynamic data collection period of up to 90 days.

:::

| Request schema | |
| --- | --- |
| `audienceName` <br /><span class="type-text">string</span> <span class="required-text">required</span> | Audience name, up to 255 characters. |
| `keywords` <br /><span class="type-text">array of strings</span> | Keywords to generate a Contextual audience. Send an empty array (<var>[]</var>) if you only use URLs. |
| `urls` <br /><span class="type-text">array of strings</span> | The publisher sites visited by a user. Each URL must include a scheme (<var>https://</var>). Send an empty array (<var>[]</var>) if you only use keywords. |
| `frequency` <br /><span class="type-text">integer</span> <span class="required-text">required</span> | The number of times a user visits the publisher(s) relevant to one or more keywords or URLs added to the Contextual audience, from <var>1</var> to <var>10</var>. |
| `timezoneId` <br /><span class="type-text">integer</span> <span class="required-text">required</span> | [Timezone ID](/guidelines/master-api#get-timezones) that sets the data collection start time. |
| `dataCollectionMethodId` <br /><span class="type-text">integer</span> <span class="required-text">required</span> | **static** (<var>1</var>): data collection over a fixed set of dates. <br />**dynamic** (<var>2</var>): data collection over a rolling timeframe, with data refreshes every 24 hours. |
| `startDate` <br /><span class="type-text">integer</span> | Unix epoch start date, in milliseconds. Required if the data collection method is **static**. |
| `endDate` <br /><span class="type-text">integer</span> | Unix epoch end date, in milliseconds. Required if the data collection method is **static**. |
| `dataCollectionDays` <br /><span class="type-text">integer</span> | Number of days in the rolling data collection timeframe, up to <var>60</var>. Required if the data collection method is **dynamic**. |
| `audienceSubtypes` <br /><span class="type-text">array of integers</span> | List of [audience subtype IDs](/guidelines/audience-api/#audience-subtype-list) to further define the Contextual audience. Healthcare workspaces only. One audience is created per subtype. <br /><EnumWidget values={audienceSubtypes} /> |
