# Audience API

The Audience API allows you to create different types of audiences for campaign targeting based on desired specifications. 

See the [Healthcare](/healthcare-vertical/audience-healthcare/) and [Political](/political-vertical/audience-segments/) verticals for specialized Audience API capabilities.

The following table describes each type of audience:

<div class="definitionsTable">
  | Type | Description |
  | --- | --- |
  | **Matched audience** | Upload a CSV or XLSX file with audience details which is then matched with IQM's user database to create a custom audience segment. 
  | **Retargeted audience** | Add a tracking tag to your website allowing you to track users who visit so they can be retargeted to receive ads in the future. 
  | **Geofarmed audience** | Define an audience by a custom geographical area.
  | **Campaign audience** | Retarget an audience associated with a campaign. 
  | **Segmented audience** | Group users by common characteristics to reach specific target audiences. 
  | **Pre-bid audience** | Select multiple pre-bid segments and group them together into an audience. 
  | **Contextual audience** | IQM adds users to an audience when they visit sites featuring specified keywords or URLs.
  | **Lookalike audience** | Analyzes an existing audience and generates a new one based on specified size and similarity percentage. 
  | **ABM audience** | Account Based Marketing (ABM) audience for [Healthcare](/healthcare-vertical/audience-healthcare/) campaigns.
  | **ICT audience** | An Integrated Care Team (ICT) audience is a type of Matched audience intended for healthcare-audience expansion. See the [Healthcare](/healthcare-vertical/audience-healthcare/) vertical for more information.
  | **Custom Voter audience** | Audiences for [Political](/political-vertical/audience-segments/) campaigns based on voter segments which are defined by a combination of demographic, psychographic, and behavioral attributes. |
</div>

### Create Audience Insights report

<CopyUrl method="POST" url="https://api.iqm.com/api/v3/audience/insights/add" />

<div class="endpoint-container">
  <div class="child1">

Generate an Audience Insights report for any given audience IDs.

This is the same mechanism as the Insights API's [Create Audience Insights report](/guidelines/insights-api#create-audience-insights-report) endpoint.

The <var>id</var> returned here identifies the report. Track its status through the Insights API's [Get a list of Insights reports](/guidelines/insights-api#get-a-list-of-insights-reports), and once ready, retrieve it via [Download Insights report](/guidelines/insights-api#download-insights-report).

:::info 

An audience must meet the following eligibility criteria to generate Audience Insights report:
  * Must be **Matched audience** type
  * Audience status: "ready"
  * Audience reach: 10,000+
  * (Recommended) Audience creation date within the last year

:::
