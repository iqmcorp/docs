# Reports API

The reports API allows you to create and schedule custom reports to generate insights and inform current and future campaign optimization.

Metrics and dimensions can be selected to customize reports. Metrics are quantitative values (number, percentage, dollar amount) measuring some campaign's attribute. Dimensions are those attributes: the chosen element (e.g. demographics, creatives, technologies) to be subjected to a metric. 

Reports can be scheduled to a specified delivery frequency, and further fine-tuned to aggregated or disaggregated (daily) data. 


<div style={{ maxWidth: "1000px" }}>
:::info

There must be at least one active campaign before a report can be created/executed. 

See the following quickstart guides:
  * [Create a campaign](/quickstart-guides/create-a-campaign-quickstart)
  * [Run a report](/quickstart-guides/reporting-api-quickstart-guide)
  * [Schedule a report](/quickstart-guides/schedule-report-api-quickstart-guide)

:::

:::warning[NOTE]

The date range for a report cannot exceed one year. 

:::
</div>

Learn more about reports with our [Help Center<ExternalLink />](https://help.iqm.com/en/articles/10343665-reports-overview) articles.

### Execute a report

<CopyUrl method="POST" url="https://api.iqm.com/api/v3/ra/report/execute" operationId="executeReportData" />

<div class="endpoint-container">
  <div class="child1">

Execute a report by ID or with new report data. Returns report rows in the response; to get a file instead, use [Get URL for report download](#get-url-for-report-download).

:::warning[NOTE]

The date range for a report cannot exceed one year. 

:::

| Request schema|  |
| ---- | --- |
| `id` <br /><span class="type-text">integer</span> | Executes report by [report ID](#get-a-list-of-reports). |
| `dimensions` <br /><span class="type-text">string</span> | Dimensions to filter by in serialized JSON format. |
| `columns` <br /><span class="type-text">array of strings</span> | Metrics for the report, from the dimensions and metrics details API. Dimensions go in <var>dimensions</var>, not here. |
| `customerIds` <br /><span class="type-text">array of integers</span> | [Customer IDs](/guidelines/workspace-api#get-multi-level-customers-list) to report. |
| `filters` <br /><span class="type-text">object</span> | Supports <var>campaignIds</var>, <var>creativeTypeIds</var>, and <var>campaignStatuses</var> arrays. <var>campaignStatuses</var> only applies when the report includes a campaign dimension. |
| `searchField` <br /><span class="type-text">string</span> | Filter rows by dimension value name or ID (partial match), e.g. campaign name. |
